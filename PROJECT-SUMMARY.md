# Hotel Raas Grand - Luxury Hotel Website

## 🏨 Project Overview

A premium, luxury hotel website for Hotel Raas Grand, Kanpur - featuring multiple properties, banquet halls, and comprehensive booking facilities.

## ✨ Key Features

### Pages
1. **Home** - Hero with booking widget, featured rooms, highlights
2. **About** - Brand story, heritage, values
3. **Rooms & Suites** - 3 room types with galleries and booking
4. **Banquet & Events** - 3 halls (Grand Ballroom, Crystal Hall, Business Suite)
5. **Restaurant** - Dining options and menu highlights
6. **Gallery** - Professional photos of property, rooms, events
7. **Location** - Interactive maps for all 3 properties
8. **Contact** - Booking form, WhatsApp integration

### Design Elements
- **Color Scheme**: Luxury gold (#B8860B), rich brown (#8B4513), cream (#FFF8DC)
- **Typography**: Playfair Display (headings), Inter (body)
- **Style**: Premium hospitality with Indian luxury aesthetics

### Technical Features
- ✅ Multi-page React application with React Router
- ✅ Responsive design (mobile-first)
- ✅ Real hotel images from provided URLs
- ✅ WhatsApp booking integration
- ✅ Google Maps embed for all locations
- ✅ SEO optimized with Schema markup
- ✅ Fast loading with lazy-loaded images
- ✅ Booking inquiry forms
- ✅ Event/banquet inquiry system
