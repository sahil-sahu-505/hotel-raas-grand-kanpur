# Hotel Raas Grand - Luxury Hotel Website

A premium, luxury hotel website for Hotel Raas Grand, Kanpur - featuring multiple properties, banquet halls, and comprehensive booking facilities.

## 🏨 Features

- **Multi-page React Application** with React Router
- **Luxury Design** - Gold/Brown premium theme
- **Real Hotel Images** from provided sources
- **Responsive Design** - Mobile-first approach
- **WhatsApp Integration** - Quick booking via WhatsApp
- **SEO Optimized** - Meta tags, Schema markup, Sitemap
- **8 Complete Pages**:
  - Home (Hero, Features, Rooms, Banquet previews)
  - About (Story, Values, Stats)
  - Rooms & Suites (3 room types with galleries)
  - Banquet & Events (3 halls with details)
  - Restaurant (Dining options)
  - Gallery (Image lightbox)
  - Location (3 properties with maps)
  - Contact (Booking form, contact info)

## 🎨 Design

- **Colors**: Luxury Gold (#B8860B), Rich Brown (#8B4513), Cream (#FFF8DC)
- **Typography**: Playfair Display (serif) + Inter (sans-serif)
- **Style**: Premium hospitality with Indian luxury aesthetics

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
